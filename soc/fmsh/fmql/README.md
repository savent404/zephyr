# FMQL SoC README

## Naming rules

```
Using 'FMQL' as prefix. for both JFMQL and FMQLM SoCs.
```

Since FMQL SoCs has diverse naming rules, which are:
- Using 'FMQL' as prefix. (FMQL10 and FMQL45) at early stages.
- Using 'JFMQL' and 'FMQLM' as prefix for specific areas. (JFMQL20S400, JFMQL20S484, FMQLM20, JFMQL15...)

We have to simplify the naming rules to make it easier to understand and use.
